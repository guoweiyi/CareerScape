# 首包美术方向与制作说明

日期：2026-10-08。职业：软件测试新人；剧本：《上线前的最后一小时》；组织：原创虚构“栖木工作室”。实际使用内置 `image_gen.imagegen` 完成风格板、人物及场景。没有使用 CLI/API 回退、网络素材代替、几何人物占位或运行时生图。

## 视觉语言

温暖都市、清爽线稿、低饱和色块与柔和明暗的 2D 轻写实视觉小说。绿植、普通设备、自然光与正常工作痕迹形成小团队生活感。画面内没有聊天正文或品牌字样，职业材料由可访问的前端文字层承载。人物均为虚构成年人；表情是叙事演出，不是学生能力或心理评价。

风格板逻辑 ID：`style-board`；源图路径与哈希见 `art/manifests/source-index.json`。先视觉检查风格板与林澄基准，再基于同一个 neutral 参考编辑每一张表情；办公室提前导出，让前端接上第一组人物＋背景＋对白，其后完成全部人物和场景。没有把不同随机人物凭名称当同一角色。

共同画布：768×1024 / 1152×1536，固定近正面略侧视、头顶约 2%—4%、脸部中心约 (0.5, 0.25)、半身下缘 (0.5, 1)。不承担手部叙事；手通常在画布外。neutral、relaxed、thinking、serious 只变化眼睛、眉毛和嘴部，严肃为关注事情而非敌意。休闲服、明显手势、困惑/疲惫表情列入 P1，当前没有混入首版。

工具实际 PNG 母版为 1086×1448 人物、1672×940 或 1672×941 场景（具体以 source-index 为准）。工具不提供尺寸参数；尊重实际格式，不声称取得分层文件或 1536×2048 原生母版。主档768×1024采用透明 contain，不扭曲人物；1152×1536是略微放大派生，不冒充原生更高细节。头像由 neutral 的同一文件裁切到 128 / 256 px，裁切框登记在 manifest。

## 设计变量与品牌

`art/ui/design-tokens.ts` 为可复用变量基准：paper #F7F4EE、surface #FFFFFF、ink #20332D、primary #285B4B、accent #A64732、muted #5C6962；正文16px/1.65，对话圆角20px、控件12px、4px间距基线。品牌图形用一个对话窗承载分岔路线，保留1/4图形边长留白；方形图标最小24px，横版字标最小160px宽；深底用浅色变体。不声称完成商标或独创性检索。

玩家界面图层：背景0 → 人物20 → 阅读承载层 → 对话与可选操作 → 全局弹窗。角色图不得遮挡对白；手机同时突出当前人物，头像承载其他成员。动态只在完成句子/回合边界切换；关闭动效后功能完整。没有音频，默认静音。

## 精确制作记录与复用模板

所有21次实际提示词、输出哈希、参考源ID和逐张自检记录位于 `art/manifests/generation-log.json`，不是空模板。

1. 基准图模板：角色ID/成年年龄/固定五官发型/服装色板＋已查看风格板；固定半身姿态、透明背景、无品牌或文字。填写实例见 lin-neutral、zhou-neutral、xu-neutral。
2. 表情编辑模板：以对应neutral为唯一人物身份参考，**只改指定表情**，保持脸型/年龄/头发/服装/画布/姿态/光线与锚点；不新增道具。填写实例见9个表情编辑记录。
3. 场景模板：职业场所/下午光线/正常设备/视觉焦点/人物与文字区域，跟随风格板；不画品牌、可读屏幕文字或真人。填写实例见4个横版场景及4个独立竖版重排记录。

运行文件在 `apps/web/public/art/`；逻辑ID与当前版本固定在 `art/manifests/careerscape-v2.json`，旧v1也保留。图片URL含内容hash，不覆盖旧版本。网页的 `manifest.json` 为当前版本指针，`manifest-careerscape-art-v1.json` / `manifest-careerscape-art-v2.json` 为不可变清单。v1派生使用数组；v2统一 `variants.retina` / `variants.mobile`。公开清单的 `reviewStatus: agent-reviewed` 如实表示执行智能体检查；发布状态与审查者独立，不将发布解释为人工审核。
