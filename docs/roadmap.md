# 分期路线图与资源前置条件

本表保留原始需求中的 P1/P2 能力，并区分首版尚未通过的验收与后续需求。P0 未通过项不因列入文档而降级成 P1。项目不以时长、成就或职业适配百分比作为学生价值的证据。

## P0 收口门槛

| 工作 | 完成依据 | 资源或限制 |
|---|---|---|
| 首包三条路线、求助、拒绝、下班、职责片段 | `tests/domain.test.ts` 与真实 UI 路线 | 领域测试已实际通过；UI 门禁单独记录 |
| 离线批次→候选→审核→发布→受约束组局 | `scripts/content/cli.ts`、数据库、后台审核与发布回退 | mock 管线真实执行；行业审核保持 pending |
| 存档、断线/响应丢失、幂等、分支、游客认领 | 服务层事务测试、浏览器恢复检查 | 不能只用前端本地缓存替代 |
| 图像与许可交付 | 12 立绘、3 同源头像、4 场景、hash manifest、运行截图 | 必须真实文件与逐张检查；任何缺项保持 P0 未完成 |
| 登录、登出、恢复、导出/删除和权限隔离 | 账号接口、实际数据库测试、页面验证 | 首版用户名密码+恢复码；无需假装接通邮件或手机号 |
| 模型契约、角色边界、失败降级 | mock 回归、SDK 类型编译、无密钥降级 | 没有真实密钥时不能宣称生成质量或费用/延迟已测 |
| 构建、lint、严格类型、单元/服务/浏览器测试 | `docs/delivery-log.md` 记录真实命令与结果 | 缺失的环境验证明确列明 |
| 生产部署准备 | HTTPS、持久卷、数据库恢复、限流/CSRF、运维说明 | 未得到部署授权前不部署；未测试的代理环境不宣称已通过 |

## P1：首轮试用后优先级

| 优先级 | 能力 | 验证前提 / 资源 | 交付边界 |
|---|---|---|---|
| P1-01 | 补足 3 个工作内容明显不同的职业包 | 实际试玩、行业合作审核者、独立角色与场景美术预算 | 工作任务有区别，不复制办公室换职业名 |
| P1-02 | 同项目多视角、更多候选人物、内容多样性评估 | 每名候选有完整角色约束与美术；明确个人资料权限 | 新角色只来自已发布库，不能随对话无限生人 |
| P1-03 | 已实现：本人结局回顾、已提交对白逐段阅读与可选自动播放；待做：可选成就、更多演出 | 已提交事件、冻结版本与本人归属；演出扩展仍需可访问性和体验研究 | 未解锁不泄露标题或正文；阅读默认手动，自动翻段不执行行动，关闭/隐藏/回合变化时停止；没有适配评分或成就；见[结局说明](endings.md)与[用户手册](user-admin-guide.md) |
| P1-04 | 本轮已实现：已有节点图形编辑；待做：新建/删除节点、拖拽、批量导入、独立子图预览 | 当前 DSL、可达性和权限门禁稳定；图形/JSON互通与两层未保存保护 | 支持标题、背景、已有对白/选项，自动同步目标边与资源引用；仅草稿可改，仍走原有保存、检查、审核与发布；见[编辑器说明](studio-editor.md) |
| P1-05 | 第二种注册方式、第三方登录、管理员 MFA | 邮件/短信/第三方资质、回调域与成本批准 | 保留原方式恢复与账户归属；不用虚假按钮 |
| P1-06 | 第二模型 provider、固定用例质量对比 | 明确调用额度、角色隐私集、模型版本与费用来源 | 用真实生成做回归；失败不重复业务效果 |
| P1-07 | 按需向量检索与评测增强 | 结构化查询已出现可测不足、来源具有 embed 权限 | 撤权可定位删除，不为凑技术栈每轮嵌入 |
| P1-08 | 真正逐段模型预览 | 逐段安全/权限校验、泄漏评估、暂存与提交协议 | 不能依赖显示后撤回消除泄漏；P0 继续完整缓冲 |
| P1-09 | 多服装/姿态、昼夜场景、结局插画、音效补充 | 试玩证明价值、许可与资产预算 | 优先可读性与复用，不机械扩增资源数量 |
| P1-10 | 组织/学校/班级、教研与教师功能 | 明确授权与参与用途、字段级访问矩阵 | 教师默认不看私聊和手账 |
| P1-11 | 灰度、A/B、数据看板 | 自愿研究、隐私同意、样本与分析计划 | 不把留存/时长视作教育成效 |
| P1-12 | CSV/Excel 导入、受限富文本、批量操作 | 大小/字段/schema/公式注入校验、撤销策略 | 正式版本与事件日志不可任意 CRUD |
| P1-13 | 工单、临时支持访问、通知 | 人工支持流程、期限、用户同意和审计 | 运营不获得全库私密全文 |
| P1-14 | 资源依赖分析、定时发布、审核灰度 | 实际运营频率与责任人；排程显式授权 | 定时任务不自动扩大模型额度或外部抓取 |
| P1-15 | 多语言、多主题 | 翻译审核、文化与可访问性验证、字体许可 | 角色/任务事实和规则保持版本一致 |

“本轮已实现”描述当前代码范围，不等于所有环境已验收。结局接口、编辑器纯函数及浏览器流程的实际命令、结果和未覆盖场景统一见[验收记录](verification.md)；未列为已实现的同条子项继续保留待做状态。

## P2：需求与成本成立后

| 能力 | 必要前置条件 | 边界 |
|---|---|---|
| 企业合作案例与更多行业 | 正式授权、来源权利、专业核验、持续更新责任 | 不声称企业背书或实时内部体验 |
| 校园 SSO、多学校、多身份授权 | 校方 IdP 接入、CAS/OIDC/SAML 能力选型、学校边界测试 | 不自写所有身份协议 |
| 多租户、审批继承、自动运营 | 真实租户需求、资源隔离与授权继承方案、审计 | 可配置内容不等于可配置服务器安全边界 |
| 自定义角色、开放 API | 权限模型稳定、版本/配额/密钥生命周期 | 外部插件不能读未授权私聊 |
| 经过设计的多周目继承、分支模板、高级子图 | 试玩证明玩法必要、循环上限、记忆隔离测试 | 只继承用户明确选择的纪念/解锁信息 |
| Live2D、部分配音、可选语音、3D | 成本/体积/设备/无障碍评估，表演与声音权利 | 动画与配音不是教育效果证据 |
| 训练数据导出或微调 | 来源具有 train 权限、可测收益、隐私退出与删除 | P0 不默认拿聊天训练模型 |
| 更复杂的多角色编排 | 简单规则已出现可测瓶颈、预算与延迟收益 | NPC 不无限互相调用，世界权限仍由服务端控制 |
| 多写吞吐与数据库迁移 | 单写 SQLite 的实测瓶颈与恢复指标 | 不把多实例共享网络盘称作水平扩容 |

## 学生价值研究

研究参与与普通游玩分开，允许拒绝。后续可以自愿比较体验前后是否能更具体描述职责、提出有依据的问题、识别工作环境差异，以及是否愿意继续探索。真实数据、样本限制和不确定性分别记录；当前没有收集学生反馈或验证教育成效。
