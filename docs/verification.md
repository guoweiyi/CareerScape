## 实际发现与修复

- Nuxt 4.6 / Nitro 2.13 Windows renderer外置路径导致构建成功但SSR 500。已将Nuxt renderer内联，生产首页实际返回200；对应上游记录见版本矩阵。
- 使用当前Nuxt实例的 `usePinia()`，修复SSR读取错误Pinia实例。
- 移动端输入聚焦后布局重排吞掉首次发送点击，已移除该重排规则并以实际发送测试确认。
- 人物头部和首页说明卡曾影响脸部可读性，调整立绘位置/高度并重拍最终截图。
- 恢复密码接口已重新登录，前端原先未更新CSRF，现同步身份并以浏览器恢复后导入/删除验证。
- 截图复核发现手账读取请求可能覆盖刚输入的新文字，改为完成读取前禁用编辑，并增加保存→刷新→重新打开内容不丢失的浏览器断言。
- 发现长对话快照/流帧容量、发布可组局门禁、资源mobile变体校验等边界，加入专门回归。
